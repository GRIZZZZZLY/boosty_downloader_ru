# Boosty downloader RU

Приложение для скачивания контента с boosty.to. Это **изменённый форк**
[boosty_downloader](https://github.com/lowfc/boosty_downloader) — автор
оригинала Rowdy Beaver. Оригинал остаётся источником: все починки, которые
не касаются русского языка и архивной раскладки, предлагаются ему обратно.

Форк сделан для одной задачи: хранить скачанное так, чтобы архив можно было
читать через год, не запуская вспомогательных скриптов.

## Чем отличается от оригинала

| | Оригинал | Этот форк |
|---|---|---|
| Язык интерфейса | английский | русский, английский переключается в настройках |
| Папка поста | `Название_uuid` или `uuid` | `ГГГГ-ММ-ДД — Название` |
| Имена файлов | `uuid.jpg`, `название.mp4` | `01. Заголовок урока.mp4` — заголовок берётся из текста над вложением |
| Файл с текстом поста | `content.md` / `content.txt` | `contents.md` / `contents.txt` |
| Дата в тексте поста | по часам компьютера | по московскому времени, как показывает сайт |
| Прерванная загрузка | файл есть — значит готов | докачивается с места обрыва, файл считается готовым только после проверки |
| Проверка после скачивания | нет | размер сверяется с API, mp4 проверяется на обрыв, zip распаковывается |
| Обрыв сети | падает вся задача | файл повторяется три раза |
| Параллельность загрузок | настройка не работала | работает |
| Что уже скачано | нигде не хранится | `downloaded_index.json` в папке автора |
| Поиск новых постов | заново запросить весь период | экран «Что нового»: одна кнопка сверяет Boosty с диском |
| Папка с русским названием в пути | приложение не запускается | работает |
| Версия Flet | 0.83 | 1.0 |

Старое поведение никуда не делось: в настройках, в пункте **«Имена папок и
файлов»**, можно выбрать **«Как у автора»** — тогда имена будут такими же, как
в оригинальном приложении.

## Установка

1. Откройте [страницу сборок](https://github.com/GRIZZZZZLY/boosty_downloader_ru/actions/workflows/build-win.yml).
2. Выберите верхнюю успешную сборку (зелёная галочка).
3. Внизу страницы скачайте архив `app_win_....zip`.
4. Распакуйте в любую папку и запустите `boosty_downloader.exe`.

Папка может быть любой, в том числе с русским названием. Оригинальное
приложение из такой папки не запускалось — падало с ошибкой
`ModuleNotFoundError: No module named 'encodings'`. Переход на Flet 1.0 это
вылечил, проверено запуском из папки «тест кириллица».

## Как пользоваться

### Вход в аккаунт

Без входа скачивается только то, что автор открыл всем. Чтобы получить свой
платный контент:

1. Откройте в приложении **Управление входом**.
2. Нажмите **«Скопировать скрипт входа»**.
3. Откройте boosty.to в браузере, убедитесь, что вы вошли в аккаунт.
4. Нажмите **F12**, перейдите на вкладку Console, вставьте скрипт, нажмите Enter.
   Если браузер ругается на вставку кода — введите `allow pasting` и нажмите Enter,
   потом вставьте скрипт ещё раз.
5. Скопируйте появившийся токен и вставьте его в приложение.

Токен живёт ограниченное время. Когда он истечёт, повторите те же шаги.

### Скачать новые посты автора

1. Главный экран → **Ещё** → **Что нового**.
2. Вставьте ссылку на автора или его никнейм, нажмите **Сверить**.
3. Приложение покажет, сколько постов на Boosty, сколько уже скачано и чего
   не хватает.
4. Нажмите **Скачать недостающее**.

Сверка работает по файлу `downloaded_index.json` в папке автора. Он
заполняется сам, когда пост скачан целиком.

### Что попадает на диск

```
Папка загрузки\
  имя_автора\
    downloaded_index.json        что уже скачано
    posts_remote.json            последний список постов с Boosty
    2024-05-18 — Название поста\
      contents.md                текст поста и дата публикации
      01. Урок 1. Введение.mp4
      02. Урок 2. Практика.mp4
      материалы.zip
```

Подпапок `videos`, `photos`, `files` нет: тип файла виден по расширению.

## Настройки, на которые стоит посмотреть

- **Имена папок и файлов** — «Архивная» (по умолчанию) или «Как у автора».
- **Максимум параллельных загрузок** — от 1 до 10. В оригинале эта настройка
  сохранялась, но не применялась; здесь применяется при запуске приложения.
- **Формат текста поста** — Markdown или обычный текст.
- **Язык приложения** — русский или английский.

## Если что-то пошло не так

Приложение пишет журнал в файл `runtime.log` рядом с собой. На экране
**Отзывы и ошибки** есть кнопка, которая копирует журнал вместе с версией и
данными системы — это то, что стоит приложить к сообщению об ошибке.

Об ошибках этого форка пишите в
[issues форка](https://github.com/GRIZZZZZLY/boosty_downloader_ru/issues), а не
автору оригинала.
